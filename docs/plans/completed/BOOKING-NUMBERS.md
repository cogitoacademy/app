# Human-readable booking numbers

Status: **Complete locally (2026-09-04)**

## Outcome

- Added an immutable, globally unique `booking.booking_number` generated by a
  PostgreSQL sequence.
- Added migration `0043_cheerful_blockbuster.sql`; existing bookings receive a
  number and the database enforces uniqueness.
- Added exact admin queue search for `12` and `#12` without changing the UUID
  route/relationship key.
- Replaced the UUID display in Operations → Booking queue with the compact
  `#N` reference.
- Added schema, repository, service, API-schema, and integration/unit coverage.

## Operational note

Apply the migration with `bun run db:migrate` before deploying the build that
uses the new field. Sequence gaps after rolled-back booking inserts are
expected; numbers are references, not a contiguous count.
